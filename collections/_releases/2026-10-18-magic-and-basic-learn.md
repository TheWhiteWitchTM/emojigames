# ✨ Magic and Basic Learn

{% include release-banners.html %}

18 October 2026. Two machines for learning.

[Magic]({{ '/games/magic/' | relative_url }}) is a small language. It is Lua, with the sharp corners filed off. Run compiles it to JavaScript and runs that. The words are colored while you type. A mistake says what to fix, and which line. 2d, 3d, and ui are already in the room.

[Basic Learn]({{ '/games/basic-learn/' | relative_url }}) is BASIC on the same picture. Colored words, plain errors, and a lesson menu. Basic I stays the 40-column machine. The prompt there is still READY.

Boot fills the screen. Escape brings the page back. Stop is the button that halts a program. The program stays in this browser.
