# Learning BASIC on BASIC I

BASIC I is a small line-numbered BASIC. It is meant for people who want to learn how early home computers worked, or who want to teach those ideas. It is not a toy and it is not only for children. The same ideas appear in modern programming; the constraints just make them easier to see.

## The two modes

**Immediate mode**  
Type a command and press Enter. The machine does it now.
