# Adventureland

You start in a dark forest. Thirteen starred treasures belong in the hollow stump. `SCORE` counts them out of 13.

## Start

Return leaves the title. R, when it is over, starts again and skips the title. `HELP` prints the words this game understands. `RESTART` begins again from inside the game.

## Words

Move with `N` `S` `E` `W` `U` `D`, or `GO` and a direction. `LOOK`, `INVENTORY`, `GET`, `DROP`.

The lines that are not directions are exact:

`SAY BUNYON`, `SAY AWAY`, `RUB LAMP`, `LIGHT LAMP`, `UNLOCK DOOR`, `YELL`, `JUMP`, `FILL`, `CATCH`, `DAM`, `POUR`.

If a line comes back as “I don’t understand,” `HELP` is that list again.

A sleeping dragon occupies the meadow and does not like mud. The bees, the dragon, the bear, and the hole will end it if you insist.
