# 🔮 About

Emoji Games is a corner of [The White Witch™](https://thewhitewitchtm.github.io/whitewitch/) ([@TheWhiteWitchTM](https://x.com/TheWhiteWitchTM)). Old terminal games, redrawn with emoji, played in the page you already have open.

Politics broke me, so I started porting old games. Then I got bored of those too and decided the emojis needed their own corner. This is that corner.

## The rules

No accounts.  
No tracking.  
No “please create an account to play a 50-year-old idea with pictures.”  
No quiet sponsors.  
Argue with the code, not the caption.

The games run in your browser. Nothing on this site asks who you are.

## How to play

Open a game and click the screen if the keys don’t land.

Pong and Snake use a plain text field. S starts the round, R starts it over. Pong moves up and down. Snake turns with the arrows or WASD.

Adventureland, Pirate Adventure, and Galaxy Hunt want words. Type a command and press Enter. `HELP` prints what that game understands.

Rogue and Hack are dungeons. You move a step at a time. Step on a thing to pick it up. In Rogue, Q drinks a potion.

Trump Super Intelligence is a conversation. Type a line and press Enter. The face changes with the mood.

The Oregon Trail asks for a number, then RETURN. On the road, RETURN stops the wagon so you can look around. Hunt and the Columbia raft use the arrows.

Witch ][ is a computer. The prompt is SPEAK. A line number stores a line. RUN starts the program. SHELF lists the programs in the box. Escape stops one that will not stop.
